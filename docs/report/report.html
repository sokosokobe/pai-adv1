1. しくみ

① 教える片付いた部屋を天井カメラで 1 枚撮る
② 見比べるVLM が、動いた物と今の場所・戻し先を答える
③ 推定する答えの点と深度から、位置・向きを 3 次元で求める
④ 戻す移動 → 掴む → 運ぶ → 置く（箱は向きも戻す）
⑤ 確かめるもう一度見比べ、残った物をやり直す
⑥ 報告する写真・結果・報告文を 1 つの HTML に
要素使ったもの
シミュレータNVIDIA Isaac Sim 6.1（Windows 11、RTX 5070）
カメラ天井の中央・高さ 2.6m・真下向き（RGB と深度、1280 × 960）。部屋全体が 1 枚に写る
VLMClaude Sonnet 5.5。いつもの写真・今の写真・物の一覧を渡し、JSON（名前・場所の言葉・画像上の点）で受け取る
動作アーム：cuMotion の RMPflow ／ 台車：格子地図の A* と比例制御

2. 想定する使い方

会議室

会議の後、机の上の備品をいつもの配置に戻す

ホテル・旅館の客室

清掃の後に備品の位置を確かめ、ずれていれば置き直す。報告が確認の記録になる

家庭

外出先から片付けを頼む。物を定位置に戻して、探し物を減らす

店舗

棚の商品の乱れを、陳列の写真どおりに戻す

部屋ごとに違う「いつもの状態」に、写真 1 枚で合わせられる。

4. 工夫した点

VLM の答えを 3 次元の目標に

VLM は画像上の点しか答えない。深度画像で点を 3 次元に直し、物の中心の高さで求めることで、戻し先のずれを 1.5cm から 0.2cm に減らした。

シミュレータの正解の値を使わない

物の位置・向きは画像から、台車の位置は天井カメラから、掴めたかは指の開きから判定する。実機でも得られる情報だけで動く。

片付けた後に確かめて、やり直す

VLM の答えは 1 回ごとに揺らぐ。評価では、最初に見逃した 1 個をこの確認で回収した。

形に応じた掴み方・置き方

直方体は向きもいつもの向きに戻し（ずれ最大 1.2°）、円柱は隣の物に手が当たらない向きで掴む。置いた後は少し上げてから離れ、倒さない。

失敗を再現して原因をつぶす

記録した VLM の答えを再生して同じ動きを再現し、物の軌跡から原因を特定した（腕の反動による台車の揺れ、指の閉じ終わりの判定）。

頼んだ人への報告

写真・結果の表・Claude が書いた報告文を 1 つの HTML にまとめる。失敗も、記録にある範囲で正直に書く。

6. 実用化に向けた課題

天井カメラという前提

会議室・店舗では見守りカメラとして付けられるが、家庭ではプライバシーへの配慮が要る。ロボットのカメラで決まった位置から撮る方法も考えられる。

指の力

物を挟む力は約 36〜40N に設定した。Franka Hand の把持力（連続 70N・最大 140N。販売店などの公開資料による）の範囲内で、現実的な値と考える。摩擦は実機で未確認。

場面の単純さ

物は 5 個で色・形がはっきり違う。戻し先がふさがっている・物が重なる・似た物がある場合は扱っていない。

実機での確認

評価はシミュレーションだけ。今後は、物の種類を増やした評価と実機での確認に取り組みたい。
