# #15 低い棚での把持と、物を持ったままの移動

- **Issue**：#15（Milestone「M2 移動を含むタスク」）
- **日付**：2026-10-25
- **タイムボックス**：1時間 ／ **実績**：約0.5時間
- **検証用コード**：`scripts/experiments/shelf_carry.py`（掴む・置くは #13 の `restorebot.sim.manipulation`、場面は `restorebot.core.scene.HOME_V2`）
- **証拠**：`outputs/m2_15/shelf_carry_step_0.5/`（`summary.json`：試行ごとの結果、`frames/shelf_cup_0/`：低い棚でコップを掴んで置く、`frames/carry_cup/`：コップを持ったまま台車を動かす。4Hz の連番画像）

## 目的

M2 の前に、次の 2 つを確かめる（設計書 5.5・9.2 の未決、16 章のリスク 9・17）。

1. 低い棚（天板 0.45m）で、5 個の物体を掴んで置けるか
2. 物を掴んで待機姿勢にしたまま台車を動かしてよいか（落とさないか、手の中でずれないか）

## 方法

- Isaac Sim 6.1、NVIDIA ドライバー 616.64。RidgebackFranka（Multiphysics 版）、物理 60Hz
- 掴む・置くは #13 の部品をそのまま使った（手先の向きは台車から物体を見た方向が基準、隣の物体を避ける向き、物を持って動く段階は手先を 0.3m/s に抑える、置いた後は 0.5 秒待って 3cm 上げてから退避）
- **1. 低い棚**
  - 台車は棚の正面（+x 側）に、前面と棚の縁の隙間 10cm で棚の方を向けて止めた（`facing_pose`：台車の中心 (-0.73, -0.30)、向き 180°）
  - 5 個の物体それぞれを、棚の作業範囲の 3 か所（(-1.45, -0.55)・(-1.45, -0.30)・(-1.45, -0.05)。左右の端と中央。台車から 0.72〜0.76m、正面から 0〜19°）から掴み、隣の位置に置いた。物体の向きは 0・0.4・0.8rad。計 15 回
  - ほかの物体は床の上（部屋の南の壁際）に置いた
  - 判定は #13 と同じ（`classify_trial`。置く位置から水平 3cm 以内、傾き 10° 以内）
- **2. 持ったまま台車を動かす**
  - M1 の止め位置で、机の上 (0.75, 0.65) に置いた物体を掴み、待機姿勢（台車座標で手先 (0.4, 0, 0.95)）にした
  - 台車を速度指令（#2 の方式：台車の x・y 関節の摩擦 0、x・y・yaw の関節に速度の目標）で、後退 0.8m → 左へ 0.5m → 右へ 0.5m → 左に 90° 旋回 → 右に 90° 旋回 → 前進 0.8m の順に動かし、各動きの後に 0.5 秒止めた
  - **速さは上限（0.5m/s・1.0rad/s）で、指令は段階的に切り替えた**（加速度を制限しない、最も厳しい条件）
  - 5 個すべて（机の物体も棚の物体も、机の上から掴んだ）
  - 計測：手先（`panda_hand`）から見た物体の位置（台車座標）の、掴んだ直後からの変化の最大値。5cm を超えたら落ちたとみなす

## 結果

### 1. 低い棚：15/15 成功

| 物体 | 成功 | 配置の誤差 [mm] |
|---|---|---|
| 赤いコップ | 3/3 | 4.4・3.3・3.6 |
| 青いペン立て | 3/3 | 3.5・1.3・4.3 |
| 緑のスプレー缶 | 3/3 | 3.8・2.9・5.0 |
| 黒いリモコン | 3/3 | 1.9・1.8・0.7 |
| 黄色い小箱 | 3/3 | 2.7・2.2・1.4 |

- 連番画像（`frames/shelf_cup_0/`）で、アームが棚の高さまで下りてコップを掴み、立ったまま置いたことを確認した。手先が台車の前面に当たることはなかった
- 机（天板 0.70m）と同じパラメータのままで掴めた。棚に対する隙間（10cm）を変える必要はなかった

### 2. 持ったまま台車を動かす：5/5 落とさず、ずれは最大 0.5mm

| 物体 | 最大のずれ [mm] | 最後のずれ [mm] | 落ちた |
|---|---|---|---|
| 赤いコップ | 0.1 | 0.1 | いいえ |
| 青いペン立て | 0.5 | 0.2 | いいえ |
| 緑のスプレー缶 | 0.4 | 0.1 | いいえ |
| 黒いリモコン | 0.5 | 0.2 | いいえ |
| 黄色い小箱 | 0.5 | 0.3 | いいえ |

- ずれが最も大きかったのは旋回（4〜5 番目の動き）の後で、それでも 0.5mm
- 連番画像（`frames/carry_cup/`）で、台車が机から下がり、旋回していること、その間コップを持ったままであることを確認した。待機姿勢のアームは台車の上に収まっていて、台車と当たらなかった
- 計画していた「加速度を制限した指令」「速さを下げた条件」は、最も厳しい条件で問題がなかったので試していない

## 結論

1. **低い棚でも、机と同じ方法・パラメータで掴んで置ける**（15/15、誤差 0.7〜5.0mm）
2. **M2 では、物を掴んで待機姿勢にしたまま台車で運んでよい**。速さの上限は設計書 8.3 のまま（0.5m/s・1.0rad/s）で、加速度の制限も要らない
   - 選ばなかった案：置く場所の近くでいったん置き直す、運ぶ間だけ速さを下げる（どちらも必要がなかった）

## 設計への影響

- 設計書 9.2 の未決（物を持ったまま台車を動かしてよいか）を解消：持ったまま、待機姿勢で運ぶ。速さの上限は 8.3 のまま
- 設計書 5.5 の未決（低い棚での把持）を解消
- 16 章のリスク 9・17 を解消
- 残ったこと
  - 今回は家具や物体から離れた所を動かしただけ。家具の近くでの動き（最後の寄せ）は #16・#17 で確かめる
  - 床の上に置いた物体（使わない物体の置き場所）に、後退した台車がかなり近づいた。M2 の場面では物体は天板の上だけなので問題ないが、確認のための置き場所は台車の動く範囲から離す
