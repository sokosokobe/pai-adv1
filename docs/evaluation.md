# 定量評価（#18）

写真 1 枚で教えた「いつもの状態」に、移動マニピュレータが部屋を戻せるかを、決まったシードで繰り返し試行して評価した（設計書 13 章）。

## 1. 条件

| 項目 | 内容 |
|---|---|
| 場面 | M2：机（天板 0.70m）と低い棚（0.45m）、物体 5 個（コップ・ペン立て・スプレー缶の円柱 3 個、リモコン・小箱の箱 2 個） |
| 散らかし方 | シードで決まる 1〜3 個を、机・棚の作業範囲の中の別の場所へ動かす（箱は向きも変える）。物体どうしの隙間 5cm 以上 |
| シード | **100〜109 の 10 エピソード**（動かす物体は 1 個 × 4、2 個 × 4、3 個 × 2、計 18 個）。開発中に使った 0〜7 は、失敗を見つけるたびに直してきたので使わない |
| 本番の条件 | VLM は Claude Sonnet 5.5（effort high）。物体の位置・向きは今の写真と VLM の答えから推定。片付けた後の確認と、1 回のやり直しあり。掴めたかどうかは指の開きで判定 |
| 比べる条件 | VLM の応答をシミュレータの真値から作る（ほかは本番と同じ）。VLM の誤りとロボットの失敗を分けて見るため |
| 判定（真値） | タスクの成功：戻し先から水平 3cm 以内。エピソードの成功：動かした物体がすべて成功。箱の向き：いつもの向きとの差（180° の範囲）が 10° 以内（成否とは別に記録） |
| 実行 | `scripts/run_eval.py`（シードごとに `run_episode.py` を別のプロセスで実行し、`core/evaluation.py` で集計）。RTX 5070、Isaac Sim 6.1 |

生のログ：`outputs/m3_18/claude/`（本番）、`outputs/m3_18/truth/`（比べる条件）。シードごとに `log.json`・`result.json`・写真・報告の画面（本番のみ `report.html`）、集計は `summary.json`・`summary.md`。

### 2.3 失敗の内訳

- **最後まで戻らなかった物体はなかった**（本番・比べる条件とも）
- **VLM の見逃しが 1 件（シード 104 の青いペン立て）**。ペン立ては机の上で、いつもの位置から左へ約 10cm（画像で約 30px）だけ動かされていた。最初の比較では、Claude はスプレー缶とリモコンだけを答えた。2 つを戻した後の確認（設計書 10 章）でペン立ての位置の違いを答え、やり直しで戻した（誤差 3.6mm）。確認とやり直しがなければ、このエピソードは失敗（2/3）だった
  - 比べる条件（真値の VLM）では見逃しがないので、この失敗は VLM の検出によるもの。机の上で近くへ少しだけ動いた物体は、遠くへ動いた物体より見逃しやすいと考えられる（1 件だけなので傾向とまでは言えない）
- **掴む動作の時間切れが 1 件（比べる条件のシード 109、緑のスプレー缶）**。指はスプレー缶を挟んでいた（開き 3.65cm）が、閉じる段階が 2 秒で時間切れになり、掴み損ねと判定された（物体は持ち上がっていないので、真値の判定とも一致）。もう一度掴んで成功した（誤差 8.8mm）。指の位置が 0.2 秒止まったことでも閉じ終わりとみなす判定（#25）が、このときは成り立たなかったと考えられる。原因は調べていない（評価の後の課題）
- **撮り直し**：撮影姿勢のアームが天板を隠したため、本番で 4 回、比べる条件で 3 回、台車を下げて撮り直した（設計書 7.2 のとおりの動き。失敗ではない）

## 3. 考察

- **ロボットの動作（移動・掴む・置く）は、この条件ではほぼ安定している**。比べる条件を含む 20 エピソード・36 タスクで、移動の失敗・落下・置く失敗はなく、掴む動作の失敗は 1 回（閉じる段階の時間切れ。もう一度掴んで成功）だけだった。開発中に見つけて直した台車の揺れ（#25）は再発しなかったが、指の閉じ終わりの判定には、まだ成り立たない場合が残っている
- **配置の誤差は、Claude のときの方が平均 0.8mm 大きい**（4.8mm と 4.0mm）。戻し先は VLM が答えた点の深度から求めるので、Claude の点が数 px ずれると戻し先もずれる、と考えられる。成功の基準（3cm）に比べて十分小さい
- **確認とやり直しの効果**：VLM の見逃しを 1 件、回収した。VLM の答えは 1 回ごとに揺らぐので、片付けた後にもう一度比べることは、成功率を上げるのに効いている
- **費用と時間**：1 エピソードあたり VLM の費用は約 $0.02、ロボットが動く時間は 25〜65 秒。部屋の片付けを頼む用途には十分に小さい
- **評価の限界**
  - 試行の数が少ない（10 エピソード）。成功率の信頼区間は広い
  - 場面が単純：物体は 5 個で、色・形がはっきり違う。物体どうしの隙間を 5cm 以上あけ、戻し先がふさがらない散らかし方に限っている（#22 は未対応）。物体が重なる・似た物体がある・床に落ちている、などの条件は評価していない
  - 物理はシミュレーションで、物体の摩擦や指のドライブの値が実機と同じかは確かめていない（設計書 16 章の 10）

## 4. 再現の方法

```powershell
.venv\Scripts\python.exe scripts\run_eval.py --vlm claude --seeds 100-109 --out outputs\m3_18\claude --report
.venv\Scripts\python.exe scripts\run_eval.py --vlm truth --seeds 100-109 --out outputs\m3_18\truth
.venv\Scripts\python.exe scripts\run_eval.py --out outputs\m3_18\claude --aggregate-only   # 集計だけ
```

Claude の応答は毎回同じとは限らないので、本番の結果（特に VLM の検出）は実行ごとに変わることがある。
